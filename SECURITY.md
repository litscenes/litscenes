# Security policy

Please do not publish a suspected vulnerability, credential, signed media URL, customer record, or private project artifact in a public issue.

Use the private contact path at <https://litscenes.ai/support/> and include only the minimum reproduction information needed. Remove API keys, tokens, phone numbers, private media, database URLs, and other personal or secret data.

Supported versions and a dedicated security mailbox will be published before the first public release. Until then, no source snapshot or development build should be represented as a supported release.
