# Concurrent project work and global LOGS

Approved implementation plan:
- Retain one runtime per project; project selection changes the visible runtime without canceling or retargeting jobs. Preserve project selections and unfinished drafts. Separate registry refresh from project teardown.
- Add durable, structured workflow jobs/events and typed provider failures with project/run/artifact identities, immutable requests, settings, prices and recovery metadata. Accept work durably before dismissing creation UI; deduplicate requests.
- Shared FIFO queues: eight image, three video, three text, two audio, two local encoding operations. Scope conflicts to the actual artifact, preserve independent work and apply completions to latest owning documents. Export saved playable artifacts while unrelated generation runs.
- Remove manual generation Pause controls, retaining media playback Pause. Persist automatic pauses for quit/crash and vendor failures. Recover known submitted jobs without another submission; unknown acceptance needs review. Vendor-account failures pause that credential across projects while other work continues. Safe bounded retries only; explicit funding/auth failures pause immediately.
- Queued jobs offer Cancel. Running jobs expose only executable cancellation or Stop after this step. Continue/Review/Check existing job follows actual recovery capability. Changed inputs/settings/pricing require review before a new paid request.
- Move sidebar Logs to a compact LOGS mini-nav at the far right of the main nav. Open a nonmodal right-aligned panel approximately 60% window width and 90% available height, leaving workspace interactive, with close/Escape and preserved filters.
- Global defaults, project/workflow/status/provider filters, search, active work first, paginated history, expandable steps and safe prompt/provenance details, explicit Open item. Preserve Scene Plan versions through project filters.
- Extend canonical local trace storage with versioned job/event records, link spend and inference records, cover generation/planning/enrichment/analysis/imports/recording finalization/export/audio/local work/repairs. Activity reads the same lifecycle. Record requests before submission and correct local event success classification. Safe provenance enabled in every build; no secrets/signed capabilities/binary payloads in history.
- Validate with existing Swift suite, build, hygiene and diff checks plus controlled local scenarios: parallel projects/artifacts, capacity queueing, duplicate submission, concurrent results, exports, quit/crash and vendor holds, provider acceptance uncertainty and Logs provenance/layout. No new test files or paid verification calls.
- Implement in the canonical public checkout, preserve preexisting work, update requirements and work logs. No commits, branches, publishing or private pin updates are authorized.
