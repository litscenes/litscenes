# Repository Provenance

LitScenes Desktop entered public history as commit `9b8c588` and tag `v0.1.0` on 2026-09-03 through a deterministic, allowlisted export from its former private monorepo home.

The export's original per-file SHA-256 inventory is preserved at `docs/provenance/initial-export-manifest.sha256`. It describes the `v0.1.0` import only; later public commits intentionally do not rewrite it.

On 2026-09-06 the public repository became the canonical source for all shared Desktop development. The private monorepo retains its earlier history and proprietary products, services, catalogs, release assets, and operational documentation. It consumes public Desktop source through a pinned revision rather than maintaining a second editable copy.

No public Git history was rewritten during this transition.
