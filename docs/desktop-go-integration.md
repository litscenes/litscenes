# Historical managed-job compatibility

The independent Desktop edition uses personal provider accounts. The executable Go account, purchase, configuration, announcement, pricing-fetch and managed transport clients have been removed.

Saved billing snapshots, quote fields, request identifiers and job history still decode. A historical managed marker cannot be used as a vendor credential and fails before network submission. The app never resumes that job by silently changing its payer. Start an explicit new run with a configured personal key to generate again.

Already downloaded managed outputs remain accessible through their local content-addressed cache after hash and byte-count verification. A missing historical output requires a previously saved copy or a new run; it cannot be fetched from a retired service. Existing project artifacts and local editing/export remain available.

Removing the Desktop client does not cancel an existing service subscription, settle a reservation, or shut down infrastructure. Service retirement and account reconciliation are separate operations outside this public app.
