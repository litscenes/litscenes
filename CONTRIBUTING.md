# Contributing

LitScenes is provided as an open-source community project. Individual support, implementation assistance, and response times are not included.

- **Bugs:** open a GitHub Issue with clear reproduction steps, your app version, and your macOS version. Reports that cannot be reproduced may be closed.
- **Questions and ideas:** use GitHub Discussions.
- **Pull requests:** not accepted yet. LitScenes is dual-licensed, and code cannot be merged until the contributor license agreement completes legal review (see `CLA.md`) — this protects a clean chain of title for everyone. When the CLA is operative this file will change. Until then, please share fixes and proposals through Issues and Discussions rather than investing in a patch.

There is no published roadmap, and no promise that any particular request will be built.

Security reports must follow `SECURITY.md`, not a public issue.
