# Changelog

All notable changes to LitScenes Desktop are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/), and this project adheres to [Semantic Versioning](https://semver.org/).

## Unreleased

- Package fonts, catalog resources and the icon library so copied apps do not rely on the developer’s build directory.

- Independent Desktop setup with personal provider keys, local catalogs and no hosted LitScenes account or graph dependency.
- Curated graph: 1,915 concepts, 1,775 relationships and 3,046 evidence records; 205 original concepts extend everyday human experience and film grammar.
- Project graph pinning retains source YAML, including compatibility with the previous bundled edition.
- Bounded, optional graph guidance in Story, with bibliographic context kept separate from creative prompts.
- 26 generated starter images bundled for verified offline browsing and reference use; historical references retain their identities.

## 0.1.0

Initial public release.

- Story spine (Goal interview, Frame Context, Scene Stories, Frame Forms) running entirely on bring-your-own-key providers.
- Local-first projects with zero telemetry.
- Scenes, shots, and cut-layer editing with local assembly and export.
- Bundled community catalog snapshot, including the starter meaning vocabulary.
